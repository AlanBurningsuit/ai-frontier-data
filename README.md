# ai-frontier-data

Public data feed for the burningsuit AI frontier showcase report.

- `data/daxbench.csv`: the public [DAXBench](https://www.daxbench.com) leaderboard, scraped daily from the public page. DAXBench is by Maxim Anatsko in collaboration with SQLBI; all credit for the benchmark and its results is theirs.
- `data/history/`: dated snapshots, written when scores change.
